# Developers Crew

Tagline: Ship code faster, from scaffold to QA.

## Skills

- Superpower: accelerate repeatable engineering tasks with repo-aware patterns.
- Context7: look up current library and framework documentation before using unstable APIs.
- MCP Builder: design and scaffold MCP servers, tools, resources, and auth boundaries.
- Skill Creator: turn repeatable workflows into portable skills.
- Webapp Testing: verify UI flows with browser checks and test automation.
- Claude-Mem: capture durable preferences and project knowledge in the right place.

## Workflow

1. Read the relevant files and existing tests.
2. Define the smallest behavior change that satisfies the request.
3. Add or update tests first when behavior changes.
4. Implement with local conventions.
5. Run focused verification.
6. Summarize changed files, tests, and residual risks.

## Done

- Code is scoped and readable.
- Inputs are validated at boundaries.
- Secrets stay in environment or secret manager.
- Tests or manual verification are reported.
