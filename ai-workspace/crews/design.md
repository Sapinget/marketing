# Design Crew

Tagline: UI that never looks templated.

## Skills

- frontend-design: production UI direction and component composition.
- web-artifacts: polished HTML/CSS/JS artifacts.
- canvas-design: custom canvas-based visuals.
- algorithmic-art: generative visuals for distinctive interfaces.
- ui-ux-pro-max: product-grade UX review and interaction polish.
- slack-gif: concise motion assets for team communication.

## Workflow

1. Identify audience, job-to-be-done, viewport, and brand constraints.
2. Inspect existing UI patterns before proposing changes.
3. Design for repeated use, not only screenshots.
4. Specify components, states, spacing, typography, and responsive behavior.
5. Verify text does not overlap and controls remain usable on mobile.

## Done

- Interface feels domain-specific.
- Visual hierarchy is clear.
- Responsive states are accounted for.
- Accessibility and empty/error/loading states are covered.
