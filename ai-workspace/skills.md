# Skill Catalog

This catalog defines when to use each AI Workspace skill. The names are intentionally model-agnostic so Claude, Codex, OpenCode, and other agents can map them to native tools, MCP servers, plugins, or prompt playbooks.

## Developers

| Skill | Use when |
| --- | --- |
| superpower | Need fast repo-aware engineering execution, scaffolding, refactoring, or bug fixing. |
| context7 | Need current framework or library documentation before implementing. |
| mcp-builder | Need to design, build, or review an MCP server, tool, resource, or auth flow. |
| skill-creator | Need to package a repeatable workflow as a reusable skill. |
| webapp-testing | Need browser, UI, E2E, responsive, or regression verification. |
| claude-mem | Need to store durable preferences, project context, or reusable memory. |
